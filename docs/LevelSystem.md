# Level System

## 1. 기본 규칙

- 초기 레벨: Lv.1
- 최대 레벨: Lv.99
- Lv.99에서는 다음 레벨로 상승하지 않는다.
- 총 필요 경험치는 Lv.1에서 Lv.99 시작까지 43,450 EXP다.

## 3. 레벨 구간별 정령 제작 재료 비용

레벨 구간은 정령 제작 재료 소모량에도 직접 영향을 준다.

| 최소 레벨 | 최대 레벨 | 재료 1종당 필요 수량 | 선택 재료 종류 수 | 총 소모량 |
|---:|---:|---:|---:|---:|
| 1 | 19 | 2 | 3 | 6 |
| 20 | 49 | 3 | 3 | 9 |
| 50 | 79 | 4 | 3 | 12 |
| 80 | 99 | 5 | 3 | 15 |

런타임 기준:

- `src/data/economy.ts`의 `CRAFTING_COST_TIERS`
- `src/data/economy.ts`의 `getSpiritCraftCostByLevel(level)`

주의:

- 제작 비용은 정령 희귀도가 아니라 플레이어 레벨 구간으로만 결정한다.

## 4. 경험치 적용 순서

경험치를 획득하면 다음 순서로 처리한다.

1. 현재 경험치에 획득 경험치를 더한다.
2. 현재 경험치가 다음 레벨 필요 경험치 이상인지 확인한다.
3. 필요 경험치를 차감하고 레벨을 1 상승시킨다.
4. 남은 경험치로 다시 레벨업 가능 여부를 확인한다.
5. Lv.99에 도달하면 레벨업 계산을 종료한다.

한 번에 여러 레벨이 상승할 수 있도록 반복 계산한다.

---

## 5. 레벨 컬러 사용

레벨 컬러는 다음 UI에 활용한다.

- 프로필 레벨 표시
- 경험치 바 강조색
- 레벨업 연출
- 레벨 배지
- 일부 해금 알림

레벨 컬러는 정령 등급 컬러와 별개의 체계로 관리한다.

정령 희귀도 컬러 토큰은 `src/data/rarity.ts`의 `SPIRIT_RARITY_TOKENS`에서 별도로 관리한다.

---

## 6. 밸런스 관리

레벨별 필요 경험치와 누적 경험치는 구글시트 API 연동 할 예정이다. 시트에서 관리한다.

누적 경험치는 직접 입력하지 않고 수식으로 계산한다.

경험치 수치를 변경한 뒤에는 다음 항목을 확인한다.

- 일반 플레이 기준 예상 만렙 일수
- 초반 레벨업 속도
- 중반 정체 구간
- 콘텐츠 해금 간격
- 하루 플레이량 대비 성장 체감

---

참고: 실제 기준값과 런타임 데이터는 `src/data/levels.ts`, `src/data/constants.ts`, 그리고 `balance/Spiria_Game_Balance_v1.0.xlsx`를 따른다.

## 7. 레벨 칭호

레벨 구간별 칭호는 다음과 같다.

| 레벨 구간 | 칭호 |
|---|---|
| Lv.1~9 | 견습 빚음꾼 |
| Lv.10~19 | 초급 빚음꾼 |
| Lv.20~29 | 정령 빚음꾼 |
| Lv.30~39 | 숙련 빚음꾼 |
| Lv.40~49 | 정령 장인 |
| Lv.50~59 | 마도 장인 |
| Lv.60~69 | 대장인 |
| Lv.70~79 | 정령 현자 |
| Lv.80~89 | 대현자 |
| Lv.90~98 | 별의 계승자 |
| Lv.99 | **스피리아의 창조자** |

메시지/배지 표기 시에는 예: `Lv.45 정령 장인` 형태로 사용한다.

### UI 표기 규칙

- 기본 형식: `Lv.{레벨} {칭호}` (예: `Lv.45 정령 장인`)
- 적용 위치: 프로필, 레벨 배지, 레벨업 토스트/알림, 일부 해금 안내
- 메인 페이지 프로필: `Lv.` 접두사 없이 숫자만 (예: `45`)
- 코드 유틸: `src/data/levelTitles.ts`의 `formatLevelLabel(level)`, `formatLevelNumber(level)` 사용
