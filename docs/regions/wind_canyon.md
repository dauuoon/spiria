# Wind Canyon

## 목적

- 바람 협곡 지역의 탐험 공통 규칙을 정리한다.

## 공통 규칙

- 탐험 중 지역 흔적과 보상 확률, 숨겨진 스테이지 해금 흐름을 포함한다.
- 지역별 보상은 공통 탐험 시스템과 동일한 구조로 관리한다.
