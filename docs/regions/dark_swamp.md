# Dark Swamp

## 목적

- 어둠 늪 지역의 탐험 공통 규칙을 정리한다.

## 공통 규칙

- 어둠 늪은 최종 지역으로 간주하며, 탐험 보상과 숨겨진 스테이지 보상을 포함한다.
- 지역별 설정은 공통 탐험 시스템 구조를 따르되, 세부 보상값은 밸런스 파일 기준으로 관리한다.
