# Starlight Forest

## 목적

- 별빛 숲 지역의 탐험 공통 규칙을 정리한다.

## 공통 규칙

- 지역 탐험 시 기본 보상과 추가 보상 흐름을 가진다.
- 지역 흔적 수집과 숨겨진 스테이지 보상은 탐험 시스템의 공통 규칙을 따른다.
- 보상 수치는 밸런스 파일 기준으로 조정한다.
