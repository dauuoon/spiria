# Volcano

## 목적

- 화산 지역의 탐험 공통 규칙을 정리한다.

## 공통 규칙

- 화산 지역은 고위험 구간으로 취급하며, 보상과 위험 요소가 함께 관리된다.
- 탐험 결과는 공통 탐험 규칙과 지역별 보상 메타로 분리한다.
