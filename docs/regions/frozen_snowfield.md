# Frozen Snowfield

## 목적

- 얼어붙은 설원 지역의 탐험 공통 규칙을 정리한다.

## 공통 규칙

- 지역 탐험은 기본 탐험 보상과 숨겨진 스테이지 보상을 포함한다.
- 지역 특성에 따라 보상 형식과 우선순위는 공통 규칙을 따른다.
