# Player System

## 1. 플레이어 레벨

- 초기 레벨: Lv.1
- 최대 레벨: Lv.99
- 최대 레벨에 도달하면 더 이상 경험치로 레벨이 상승하지 않는다.

플레이어 경험치는 다음 콘텐츠에서 획득한다.

- 탐사
- 의뢰 완료
- 특별 보상
- 추후 추가되는 업적 또는 이벤트

---

## 2. 마력

마력은 탐사에 입장할 때 사용하는 행동 자원이다.

### 기본값

- 최대 마력: 5
- 게임 시작 시 마력: 5
- 탐사 1회 소모량: 1
- 마력 1 회복 시간: 20분
- 마력 0에서 5까지 자연 회복 시간: 100분

### 회복 규칙

- 마지막 마력 계산 시점부터 경과한 시간을 기준으로 회복량을 계산한다.
- 20분마다 마력 1을 회복한다.
- 최대 마력 이상으로 자연 회복되지 않는다.
- 앱이 종료된 상태에서도 경과 시간을 계산한다.
- 마력이 최대치인 동안에는 추가 회복 시간이 누적되지 않는다.

### 예시

- 현재 마력: 2
- 앱을 종료한 뒤 65분 경과
- 회복량: 3
- 최종 마력: 5

65분 중 최대치를 초과한 나머지 시간은 별도로 저장하지 않는다.

---

## 3. 탐사 입장 조건

탐사 입장 시 다음 조건을 확인한다.

1. 현재 마력이 탐사 소모량 이상인지 확인한다.
2. 조건을 충족하면 마력을 차감한다.
3. 마력이 부족하면 탐사를 시작하지 않는다.
4. UI에 남은 회복 시간을 표시한다.

---

## 4. 저장 데이터

플레이어 데이터에는 최소한 다음 값이 필요하다.

- 현재 레벨
- 현재 경험치
- 현재 마력
- 마지막 마력 갱신 시각
- 보유 골드
- 보유 재료
- 발견한 정령
- 완료한 의뢰
- 해금된 지역

클라이언트 프로토타입에서는 로컬 저장소를 사용할 수 있다. 추후 서버 저장 구조가 추가될 경우 동일한 데이터 모델을 유지한다.
