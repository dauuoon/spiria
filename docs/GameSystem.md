# Spiria Game System

## 1. 게임 개요

Spiria는 탐사를 통해 마법 재료를 수집하고, 세 가지 재료를 조합해 새로운 정령을 제작하는 모바일 세로형 판타지 게임이다.

플레이어는 의뢰서에 제시된 단서를 해석해 적절한 재료를 선택하고 정령을 제작한다. 제작 결과에 따라 경험치, 골드, 재료, 도감 등록 등의 보상을 획득한다.

- 최대 레벨: Lv.99
- 메인 컬러: `#A894FF`
- 기본 화면 비율: 모바일 세로형
- 핵심 콘텐츠: 탐사, 재료 수집, 의뢰, 정령 제작, 도감 수집, 성장

---

## 2. 핵심 플레이 루프

탐사  
→ 재료 획득  
→ 의뢰 확인  
→ 재료 3개 선택  
→ 정령 제작  
→ 제작 결과 및 정답률 확인  
→ 경험치·골드·도감 보상 획득  
→ 레벨 상승  
→ 새로운 지역과 콘텐츠 해금

---

## 3. 콘텐츠 역할

### 탐사

탐사는 정령 제작에 필요한 재료를 수집하는 핵심 콘텐츠다.

탐사에서는 다음 보상을 획득할 수 있다.

- 재료
- 소량의 플레이어 경험치
- 소량의 골드
- 랜덤 이벤트 보상

또한 각 지역의 흔적을 20개 모으면 해당 지역의 Hidden Stage에 진입할 수 있다.

- 탐험 맵에서 조건 충족 시 해당 지역 노드에 `!` 알림 아이콘 표시
- 입장 시 분기 선택 제공
	- 아니요: 기존 탐험 입장 (마나 소모)
	- 네: Hidden Stage 입장 (지역 흔적 20개 소모)
- Hidden Stage는 일반 맵과 동일한 탐험 흐름을 사용하되 배경/보상 밸런스가 별도로 적용된다.

### 의뢰

의뢰는 어떤 정령을 제작해야 하는지 간접적인 단서를 제공한다.

플레이어는 의뢰 내용을 해석하고 적절한 세 가지 재료를 선택한다. 의뢰는 플레이어 경험치와 골드를 획득하는 주요 콘텐츠다.

### 정령 제작

플레이어는 세 가지 재료를 선택해 정령을 제작한다.

재료는 정령의 몸을 문자 그대로 구성하지 않는다. 재료의 성질과 이미지는 정령의 성격, 속성, 마법적 특징에 반영된다.

### 도감

제작한 정령은 도감에 등록된다.

도감은 다음 정보를 제공할 수 있다.

- 정령 이름
- 정령 등급
- 영감이 된 재료
- 발견 여부
- 성장 단계
- 간단한 설명

---

## 4. 플레이어 성장

플레이어는 탐사와 의뢰를 통해 경험치를 획득한다.

레벨이 상승하면 새로운 탐사지역, 의뢰, 재료, 정령 제작 콘텐츠가 순차적으로 해금된다.

최대 레벨은 Lv.99다.

## 6. 데이터 관리 원칙

게임 시스템 설명은 `docs` 폴더에서 관리한다.

게임 밸런스 수치의 원본은 `balance/Spiria_Game_Balance_v1.0.xlsx`에서 관리한다.

실제 게임에서 사용하는 데이터는 `src/data` 폴더에서 관리한다.

Hidden Stage 보상 테이블은 `src/data/hiddenStage.ts`의 `HIDDEN_STAGE_BALANCE`에서 관리한다.

UI 컴포넌트와 게임 로직 내부에 경험치, 골드, 마력 회복 시간 등의 수치를 직접 하드코딩하지 않는다.

참고: 확정 수치의 실제 기준은 엑셀과 `src/data`이며, 문서 내 숫자는 설명 목적으로만 표시될 수 있다.
