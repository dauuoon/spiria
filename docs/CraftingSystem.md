# Crafting System

## 1. 핵심 규칙

- 정령 제작에는 서로 다른 재료 3종을 사용한다.
- 같은 재료는 중복 선택할 수 없다.
- 재료 선택 순서는 결과 판정에 영향을 주며 반드시 보존한다.
- 제작 키 생성 시 재료 ID를 정렬하지 않는다.

예시:

- `water>wind>gem`
- `gem>water>wind`

위 두 조합은 서로 다른 레시피로 취급한다.

런타임 구현:

- `src/lib/crafting.ts`의 `buildOrderedRecipe(materialIds)`

## 2. 레벨 구간별 제작 비용

런타임 데이터:

- `src/data/economy.ts`의 `getSpiritCraftCostByLevel(level)`

## 3. 제작 처리 순서

1. 선택된 3종 재료를 선택 순서 그대로 유지한다.
2. 현재 레벨로 필요 수량을 계산한다.
3. 각 재료의 보유 수량이 필요 수량 이상인지 검증한다.
4. 제작 시작 요청이 성공하면 3종 재료를 각각 필요 수량만큼 차감한다.
5. 제작 시작 실패/취소/중복 요청에서는 재료를 차감하지 않는다.

---

## 4. UI 규칙

- 재료 수량이 0인 항목은 비활성 상태로 표시한다.
- 선택된 재료는 선택 순서 배지를 표시한다.
- 선택된 재료가 필요 수량보다 부족하면 부족 수량까지 표시한다.
- 제작 버튼은 조건 충족 시 활성, 미충족 시 비활성이다.
- 제작 버튼 색상 규칙:
	- 비활성: 실버 배경(`btn_bg_sliver.png`)
	- 활성: 보라 배경(`btn_bg_purple.png`)
- 조합식 슬롯에는 재료명을 크게 표시하고 슬롯 우상단에 순서 번호를 배치한다.

---

## 5. 의뢰 수락/거절 규칙

- 의뢰는 `정령 의뢰서` 패널에서 `수락` 또는 `거절`로 처리한다.
- `수락`한 의뢰가 있을 때만 제작 시작이 가능하다.
- 제작 시작이 성공하면 수락 의뢰는 즉시 완료 처리되어 목록에서 제거된다.
- `거절`한 의뢰는 즉시 목록에서 제거된다.
- 거절 패널티: 코인 `-200`.
- 코인 차감 시 코인 효과음(`assets/sound/num_coin.mp3`)을 1회 재생한다.

목표 정령 표시 규칙:

- 의뢰의 목표 정령이 아직 미발견 상태면 `???`로 표시한다.
- 실제 내부 의뢰 ID/목표는 유지되며, 표시만 마스킹한다.
